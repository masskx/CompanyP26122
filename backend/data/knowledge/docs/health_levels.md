# 设备健康等级判定说明（示例知识文档）

本文件说明本系统的设备健康分类规则，供智能助手回答相关问题时引用。

## 1 四类健康等级

- normal：所有指标均可判定，且未超出配置的预警或报警限值。
- watch：存在超出报警限值的个别样本，或连续若干样本超出预警限值。
- inspect：连续若干样本超出报警限值，建议安排授权人员核查。
- insufficient_data：缺少数据、数据完整率不足或未配置判定阈值，无法给出结论。

## 2 判定参数

连续超限的样本数由配置项 RULE_CONSECUTIVE_BREACHES 决定，默认值为 3。
数据完整率的最低要求由 RULE_MIN_COMPLETENESS 决定，默认值为 80%。
设备的限值（warn_high、alarm_high 等）在设备清单 devices.json 中配置。

## 3 原则

健康等级始终由确定性规则判定，大模型只负责解释和组织结果。
未配置阈值的指标一律判为 insufficient_data，系统不会推测缺失的数据或阈值。
所有维护建议仅供人工核查，不会触发设备控制或工单流转。
