# 设备异常等级判定说明（示例知识文档）

本文件说明本系统每日分析的异常等级规则，供智能助手回答相关问题时引用。

## 1 三类异常等级

- watch（需关注）：剂量率连续超过一级阈值，或设备上报一级报警；蓄电池电压低于预警值、市电正常时电压异常下降、市电恢复后充电时间明显变长。
- inspect（需检修）：剂量率连续超过二级阈值，或设备上报二级报警；设备上报故障；蓄电池电压低于报警值。
- insufficient_data（数据缺失）：设备离线、通信中断、采样中断、全天无数据、读数长时间不变或数据完整率不足。

正常设备不生成记录。一台设备的等级取其最严重的异常事件。

## 2 判定参数

连续超阈值的样本数由配置项 ANALYSIS_CONSECUTIVE_SAMPLES 决定，默认值为 3。
相邻样本间隔超过采样周期的 3 倍视为采样中断（ANALYSIS_GAP_INTERVALS）。
剂量率一级/二级阈值、校准系数、蓄电池预警/报警电压在监测站配置表（station_config）中按站配置。

## 3 原则

异常等级始终由确定性规则判定，大模型只根据规则给出的证据撰写说明。
未配置阈值的监测站不生成设备记录，只在批次中记录一条配置缺口；系统不会推测缺失的数据或阈值。
所有维护建议仅供人工核查，不会触发设备控制或工单流转。
