# 数据缺口处理说明（示例知识文档）

## 1 常见数据问题

- 全天无数据：分析窗口内没有任何可用样本，记录明确标记为数据缺失。
- 设备离线或通信中断：数据源上报离线或通信中断，期间没有可用样本。
- 采样中断：相邻可用样本的间隔超过采样周期的 3 倍。
- 读数长时间不变：连续相同读数（标准差为零）持续 60 分钟以上，疑似探测器卡滞。
- 未配置判定阈值：监测站没有一级/二级阈值，不生成设备记录。

## 2 数据完整率的计算

数据完整率等于有效样本数除以期望样本数，期望样本数由时间范围长度除以监测站的采样周期得到。
例如采样周期为 30 秒的监测站，24 小时内期望样本数为 2880 个。

## 3 通信中断

监测设备通信中断期间不会产生读数，表现为数据缺口而不是零值。
系统不会对中断期间的数据进行插值或补齐；同比、环比缺少历史数据时标记为不可用并说明原因，不按 0 处理。
