# 数据缺口处理说明（示例知识文档）

## 1 常见数据问题

- 时间范围内无有效数据：设备离线或尚未接入。
- 数据完整率不足：实际样本数低于期望样本数的要求比例。
- 未配置判定阈值：设备清单中该指标没有 warn/alarm 限值。

## 2 数据完整率的计算

数据完整率等于有效样本数除以期望样本数，期望样本数由时间范围长度除以设备的期望采样间隔（interval_seconds）得到。
例如采样间隔为 30 秒的设备，24 小时内期望样本数为 2880 个。

## 3 通信中断

监测设备通信中断期间不会产生读数，表现为数据缺口而不是零值。
系统不会对中断期间的数据进行插值或补齐。
