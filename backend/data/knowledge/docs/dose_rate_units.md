# 剂量率单位与换算（示例知识文档）

本文件是示例知识库文档，用于联调检索、引用和权限过滤，不构成电站技术规程。

## 1 常用单位

剂量率表示单位时间内的剂量，系统中统一使用微希沃特每小时（µSv/h）存储和展示。
采集到的其他单位会在入库前换算为 µSv/h。

## 2 换算关系

1 Sv/h 等于 1000 mSv/h。1 mSv/h 等于 1000 µSv/h。1 µSv/h 等于 1000 nSv/h。
因此，85 nSv/h 换算后为 0.085 µSv/h，2 mSv/h 换算后为 2000 µSv/h。

## 3 系统处理规则

采集服务支持 nSv/h、µSv/h（也接受 uSv/h 写法）、mSv/h 和 Sv/h。
无法识别的单位、缺少单位或负数剂量率的报文会被拒绝，并按原因计数，不会写入时序数据库。
