# 剂量率单位与换算（示例知识文档）

本文件是示例知识库文档，用于联调检索、引用和权限过滤，不构成电站技术规程。

## 1 常用单位

固定监测站的 γ 剂量率统一使用微戈瑞每小时（µGy/h）存储、分析和展示。
采集到的其他戈瑞单位会在入库前换算为 µGy/h。

## 2 换算关系

1 Gy/h 等于 1000 mGy/h。1 mGy/h 等于 1000 µGy/h。1 µGy/h 等于 1000 nGy/h。
因此，85 nGy/h 换算后为 0.085 µGy/h，0.002 mGy/h 换算后为 2 µGy/h。

## 3 系统处理规则

采集服务支持 nGy/h、µGy/h（也接受 uGy/h 写法）和 mGy/h。
以希沃特（Sv）为单位的报文会被拒绝：Sv 与 Gy 之间的换算系数需由电站确认后才能配置。
无法识别的单位、负数剂量率的报文会被拒绝，并按原因计数，不会写入时序数据库。
分析时使用的剂量率等于上报值乘以该站配置的校准系数。
