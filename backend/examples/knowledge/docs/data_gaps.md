# 数据缺口处理说明（示例知识文档）

## 1 数据缺口类型

- no_data：时间范围内没有有效数据。
- low_completeness：实际样本数低于期望样本数的要求比例。
- threshold_not_configured：指标没有配置判定阈值。
- no_metrics：设备未配置监测指标。

## 2 数据完整率的计算

数据完整率等于有效样本数除以期望样本数，期望样本数由时间范围长度除以设备的期望采样间隔得到。
例如采样间隔为 30 秒的设备，24 小时内期望样本数为 2880 个。

## 3 通信中断

监测设备通信中断期间不会产生读数，表现为数据缺口而不是零值。
系统不会对中断期间的数据进行插值或补齐。
